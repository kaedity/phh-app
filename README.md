# Personal Health Hub (app code)

A personal iPhone app (SwiftUI) for one person's meals, training, sleep and body weight,
with a Google Apps Script backend that the owner runs in their own Google account.

This repository contains code only. It contains no personal records, photos, accounts,
file IDs or credentials. To run it you need your own Google project, Apps Script deployment
and connection settings (not included).

- `Hub/App`: iPhone app
- `Hub/Core`: shared Swift package (models, sync, tests)
- `Hub/Server`: Apps Script backend and its Node tests
- `Hub/Website`: description, privacy and terms pages used for OAuth

Built for personal use. No support is provided.
